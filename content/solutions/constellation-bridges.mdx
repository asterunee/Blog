> 이 글은 콘텐츠 구조를 보여 주기 위한 **예시 콘텐츠**이며 실제 온라인 저지 문제의 정답이 아닙니다.

## 처음의 관찰

두 별이 같은 성단에 속하는지만 반복해서 묻는다. 경로 자체보다 연결 여부가 중요하다는 점을 먼저 적었다.

## 풀이를 도출한 과정

매 연결을 그래프 탐색으로 확인하면 관측이 누적될수록 비싸진다. 합쳐진 집합의 대표만 기억하면 질문을 거의 상수 시간에 처리할 수 있다.

## 핵심 아이디어

각 정점을 하나의 집합으로 시작하고 관측 간선을 볼 때마다 DSU로 합친다. 질문의 두 정점 대표가 같다면 연결되어 있다.

## 정당성 증명

처리한 간선으로 연결된 두 정점은 union 연산의 추이성에 의해 같은 대표를 갖는다. 반대로 같은 대표를 가진 두 정점은 지금까지 합쳐진 간선들로 연결되는 경로가 존재한다.

## 시간·공간 복잡도

$M$번의 연산은 $O(M\alpha(N))$, 공간은 $O(N)$이다.

## 구현 과정

```cpp
// file: main.cpp; highlight: 8,12
#include "library/template.hpp"
#include "library/datastructure/union_find/union_find.hpp"

using namespace std;
using namespace suisen;

int main() {
    int n, q; cin >> n >> q;
    UnionFind uf(n);
    while (q--) {
        int t, u, v; cin >> t >> u >> v;
        if (t == 0) uf.merge(u, v);
        else cout << uf.same(u, v) << '\\n';
    }
```

## 틀렸던 접근과 반례

방향성이 있다고 착각해 인접 리스트를 만들었다. 그러나 합치기 연산은 대칭이므로 불필요했다.

## 디버깅 기록

1-indexed 입력을 0-indexed 라이브러리에 그대로 전달한 실수를 작은 두 정점 예제로 발견했다.
